# Tienda Online

Este proyecto es una tienda online desarrollada con **HTML, CSS y JavaScript**. Incluye un sistema de carrito de compras, navegación entre secciones y un formulario de contacto/registro.  
La aplicación está publicada en **Netlify** para acceso público:
https://dantienda.netlify.app/


---

## Características principales

- Carrito de compras: agregar, eliminar y ver productos seleccionados.  
- Barra de navegación: acceso a las distintas secciones de la tienda.  
- Formulario: para contacto.  
- Responsive Design: adaptable a diferentes dispositivos.  

## Tecnologías utilizadas

- HTML5 → estructura de la aplicación.  
- CSS3 → estilos, diseño responsivo y animaciones.  
- JavaScript → lógica del carrito y manejo de eventos.
